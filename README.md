# Number Guesser Game

A simple, interactive command-line number guessing game built in Python. The program generates a random number between 1 and 10 and gives the user directional feedback until they guess it correctly.

## Prerequisites

* Python 3.x installed on your machine.
* No external libraries or installations required.

## How to Run

1. Clone this repository to your local machine:
   ```bash
   git clone [https://github.com/rohanjadhav7/number-guessing-game-.git](https://github.com/rohanjadhav7/number-guessing-game-.git)
   ```
2. Navigate to the project folder:
   ```bash
   cd number-guessing-game-
   ```
3. Run the script:
   ```bash
   python gusser..py
   ```

## Example Output

```text
Welcome to the Number Guesser!
I am thinking of a number between 1 and 10.
Enter your guess: 7
Too high! Try again.
Enter your guess: 6
Spot on! The number was 6.
```
